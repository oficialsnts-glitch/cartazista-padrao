Enviar sua página (modelo)

A página inteira é enviada como um único modelo — 1, 2 ou 4 por folha — exatamente como está montada. Cada usuário recebe idêntico ao abrir o app.

Modelos de cada usuário

Cada usuário aparece como um modelo (a página dele). Compartilhe (para os destinatários acima) ou clone para a sua página.

Modelos salvos de todos os usuários

Veja os modelos salvos por cada usuário (agrupados por pasta). Copie um modelo para a sua tela, edite e depois use Replicar minha tela — ou Replicar um modelo direto para os destinatários acima. Cada usuário recebe uma cópia editável em "Modelos salvos".
